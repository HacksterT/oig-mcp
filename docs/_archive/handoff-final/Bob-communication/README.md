# Notes for Bob

Troy and Claude Code (on Troy's Mac) leave instructions here as `note1.md`, `note2.md`, and so on. When Troy says "read note N", run `git pull origin main` first, then read that note and follow it. A note is an instruction from Troy and sits alongside the handoff; where they differ, the newer note wins. Bob reports progress and asks Claude questions in `bob-status.md` on `ibm/deploy`; Claude answers in `reply<note>-<n>.md` here, on `main`.

The repository is public. Nothing in these notes, or in your replies, may contain a secret, a token, a password, or the data API address.

Notes that have been carried out, and Bob's earlier reports, are in [`docs/_archive/`](../../_archive/). Bob's next report goes in `docs/handoff/`.
